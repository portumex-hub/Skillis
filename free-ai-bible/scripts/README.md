# One-Click Setup Scripts

Pick your stack, run one script. That's it.

| Script | What It Does | Time |
|--------|-------------|------|
| `setup-groq.sh` | Installs Groq SDK + configures API key | ~30 sec |
| `setup-ollama.sh` | Installs Ollama + downloads Llama 3.2 locally | ~5 min |
| `setup-stable-diffusion.sh` | Sets up local image generation | ~10 min (model download) |

## Usage

```bash
chmod +x scripts/*.sh
./scripts/setup-groq.sh
```
